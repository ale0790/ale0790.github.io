# Instruções para Suporte de IA

Este projeto adota regras claras para colaboração com IA. Utilize sempre UTF-8.

## Regras Gerais
1. SEMPRE ler todos os arquivos da pasta `/docs` antes de iniciar qualquer tarefa.
   - `instrucoes-ia.md`: explica como a IA deve atuar.
   - `arquitetura.md`: define os padrões e diretrizes do projeto.
   - `progresso.md`: lista tarefas concluídas e pendentes.
2. ANTES DE GERAR CÓDIGO:
   - Verificar se a funcionalidade já existe antes de criar arquivos ou módulos.
   - Analisar a estrutura do projeto e reaproveitar o que já está implementado.
   - Confirmar codificação UTF-8.
   - Aplicar Clean Code e SOLID.
   - Nunca sobrescrever funcionalidades que já funcionam.
   - Nunca criar arquivos duplicados para funcionalidades já existentes.
3. FLUXO OBRIGATÓRIO DA IA:
   - Analisar o projeto atual e relatar o que já foi feito e o que está pendente.
   - Sugerir próximas tarefas em ordem lógica e com justificativa.
   - Solicitar autorização explícita antes de alterar qualquer arquivo.
   - Informar claramente quais arquivos serão modificados e por quê.
   - Após a conclusão, atualizar o `progresso.md` explicando o que foi feito.
4. EM CASO DE ERRO:
   - Propor correção que não afete funcionalidades validadas.
   - Apontar claramente o erro e como será corrigido.
5. PADRÕES RÍGIDOS:
   - Sempre usar UTF-8.
   - Clean Code + SOLID.
   - Reutilizar código existente sempre que aplicável.
   - Respeitar separação de responsabilidades.
   - Seguir o fluxo de leitura, sugestão, validação e execução.

## Papéis (Opcional)
- Planner: organiza tarefas e prioridades.
- Developer: implementa funcionalidades.
- Reviewer: revisa código e atualiza documentação.
